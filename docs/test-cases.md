## เกณฑ์ผ่าน

- TC-01 ถึง TC-15 ต้องผ่านทุกข้อก่อนเดโม
- TC-16 ตรวจด้วย Responsive mode ของ DevTools อย่างน้อย 375px และ 1280px
- ตรวจเวลาตอบสนองของการค้นหาและส่งคำขอให้ต่ำกว่า 3 วินาทีตาม NFR-02
